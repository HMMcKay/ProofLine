Developer guide

Build and run ProofLine locally.

The repository contains three working surfaces: a Vinext/Sites public control plane, a Rust media plane, and a native Android client. Start the web and media planes first; then point the Android app at the control-plane URL.

The scripted Windows path checks required tools and preserves an existing .env. It will not overwrite secrets or remove Docker volumes.

Clone

git clone <repository-url> ProofLine
cd ProofLine

This checkout currently has no Git remote configured, so the documentation intentionally uses a placeholder rather than inventing an owner URL.

Fast path on Windows

Set-ExecutionPolicy -Scope Process Bypass
./scripts/setup-local.ps1
./scripts/start-local.ps1

setup-local.ps1 checks the host, copies .env.example only when .env is missing, installs pinned Node dependencies, and validates the Docker Compose model. start-local.ps1 starts the container media plane, then keeps the Vinext development server in the foreground.

Public/control plane

http://localhost:3000

Media plane through Caddy

http://localhost:8080

Press Ctrl+C to stop the foreground web server. Stop containers separately:

./scripts/stop-local.ps1

Manual start

Copy-Item .env.example .env
npm ci
$env:npm_config_script_shell = "C:\Program Files\Git\bin\bash.exe"
docker compose up -d --build --wait
npm run dev

The Compose defaults are development-only. Replace every secret before exposing the service beyond localhost.

Android client

The debug app defaults to http://10.0.2.2:3000, which maps an Android emulator to the host. For a physical phone, supply a control-plane URL reachable over the local network or HTTPS.

cd android
./gradlew.bat testDebugUnitTest lintDebug assembleDebug

Override the endpoint for a build:

./gradlew.bat assembleDebug -PprooflineControlUrl=https://proofline.example

Create the full deliverable set—including development-signed release outputs and the clean-payload reproducibility check—from the repository root:

./scripts/build-android-artifacts.ps1
Release trust: development artifacts use an ephemeral self-signed key. Production signing requires environment-provided keystore values and a protected release process.

Documentation site

npm run docs:check
npm run docs:serve

The local documentation server prints its URL and serves the same docs/ directory deployed by GitHub Pages. Stop it with Ctrl+C.

Verification shortcuts

./scripts/verify-local.ps1

# Include Rust and the slower container scenario
./scripts/verify-local.ps1 -IncludeRust -IncludeContainers

# Include every locally automated surface
./scripts/verify-local.ps1 -IncludeRust -IncludeContainers -IncludeAndroid -IncludeC2pa

See the validation record before treating a local pass as physical-device or production evidence.

Common issues

Vinext shell errors
On Windows, set npm_config_script_shell to Git Bash. The helper scripts do this automatically.
Port 3000 or 8080 busy
Stop the prior development server or Compose project. Do not run multiple ProofLine stacks against the same persistent volumes.
Android cannot reach host
Use 10.0.2.2 only in the emulator. A physical phone needs the host’s LAN address and a development network-security policy or HTTPS.
Containers unhealthy
Run docker compose ps and docker compose logs gateway worker. Storage failure intentionally makes ingest fail closed.
