Documentation / Architecture

System design

Separate public control from continuous media work.

Sites serves the public web and short control-plane APIs. A dedicated HTTPS media plane owns long-lived ingest, durable receipts, media delivery and evidence finalization.

Topology

Capture

Android + PWA

Enroll a pseudonymous key, create a capture session, sign short media fragments and telemetry, retain unacknowledged material locally, and submit a signed end when possible.

Control

Sites/Vinext + D1

Public pages, device/capture APIs, capability issuance, location-release policy and a public read model fed by authenticated idempotent ledger events.

Media

Caddy + Rust services

Gateway, worker, PostgreSQL and S3-compatible storage. The media plane performs byte hashing, signatures, persistence, finalization, reports and downloads.

Cloudflare Workers never run FFmpeg, C2PA authoring, PDF generation or long-lived upload streams. That boundary keeps bounded edge requests separate from stateful media processing.

Data authority

PostgreSQL
Authoritative workflow, captures, streams, fragment index, jobs, leases, receipt anchors, outbox and immutable audit events.
MinIO / S3
Exact received objects and derived HLS, reports, C2PA outputs and bundles. Original keys are never overwritten.
D1
Public read projection for fast Sites pages. It is not the evidence authority and can be rebuilt from ledger events.
Device queue
Encrypted bounded buffer for material not yet acknowledged. Acknowledged fragments are deleted first under storage pressure.

Trust boundaries

Device identity key

Long-lived, non-exportable P-256 key where supported. It signs the session binding and end manifest, not every media fragment.

Capture session key

Ephemeral P-256 key for high-frequency fragment and telemetry envelopes. Its authority is limited to one capture.

Server receipt key

Signs durable-receipt facts and report signatures. Private material stays outside PostgreSQL and D1.

Offline admin key

Signs tombstone actions. Only its public key belongs on the server; no browser administration account is added.
